Hugo 博客入门教程

March 27, 2026

本文介绍如何使用 Hugo 快速搭建个人博客。

什么是 Hugo？#

Hugo 是一个用 Go 语言编写的静态网站生成器，具有以下特点：

  • 快速 - 构建速度极快，毫秒级完成
  • 简单 - 配置简单，上手容易
  • 灵活 - 支持多种主题和自定义
  • 无数据库 - 基于 Markdown 文件

文章结构#

Hugo 文章由两部分组成：

Front Matter（元数据）#

放在文章顶部的配置区，包裹在 +++ 中：

+++
date = '2026-03-27T22:00:00+08:00'
draft = false
title = '文章标题'
tags = ['标签1', '标签2']
categories = ['分类']
+++

Markdown 内容#

元数据下方是正常的 Markdown 内容，支持：

  • 标题、列表、链接
  • 代码块（支持语法高亮）
  • 图片
  • 表格

部署流程#

  1. 在 content/post/ 目录下创建 .md 文件
  2. 运行 hugo 构建静态文件
  3. 将 public/ 目录内容部署到服务器

开始写作#

现在你可以开始创建自己的博客文章了！
